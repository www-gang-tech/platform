# GANG — visual direction

The product should occupy more space than the language. Use the photographs to show form, scale, attachment, and placement. Use text to identify, explain, and answer.

A useful starting point is roughly three quarters of the opening viewport devoted to the object and its setting. This is a creative target, not a fixed ratio or conversion claim. On smaller screens, prioritize a legible product, the category sentence, and a clear next action over preserving a desktop crop.

## Composition rules

- One visual idea per section. Do not place six tiny feature cards where one precise demonstration would be clearer.
- Use a quiet neutral canvas, generous space, and a small type hierarchy. Take colors and type from the approved GANG identity when available.
- Product edges, spacing, and alignment should define the layout. Avoid ornamental gradients, floating glass panels, and generic technology motifs.
- Keep ordinary links and controls recognizable. Minimal navigation must still be easy to find and use.
- Place most copy beside or below the image. If overlaying it, choose a crop with a reliably clear area and verify contrast.
- Use motion only to explain a real action: attachment, scale, or the relationship between parts. No scroll hijacking or decorative loading sequence.
- Keep the physical product accurate. No generative substitute for the final geometry, mounting configuration, finishes, or certification marks.
- Use a still poster when motion is unavailable or reduced. Provide a pause control for ongoing animation and captions for spoken information.

## Asset delivery

Deliver original files and optimized derivatives separately. Name derivatives by product and view, for example `gang-4-in-1-wall-front.webp`. Supply source, rights, credits, product revision, crop, and alt text with each asset. A prototype photograph needs a visible prototype caption wherever the differences could affect purchase expectations.

Use actual image elements with responsive sizes and descriptive context. Google explains how image placement, alt text, and discoverable image URLs help it understand visual content. [Google Image SEO guidance](https://developers.google.com/search/docs/appearance/google-images)

Load the first major image promptly; defer below-the-fold imagery. Reserve image dimensions to keep the layout stable. Keep video optional and use a compact poster. The opening image is likely to be the Largest Contentful Paint element; loading it late can delay the page's perceived arrival. [web.dev LCP guidance](https://web.dev/articles/optimize-lcp)

The existing project budgets all page images at 500 KB. Validate a real image set against that limit before promising a rich long-form product gallery. If the gallery cannot fit, make an explicit measured budget decision; do not silently ship oversized assets. Preserve useful detail, especially for material and installation views.
