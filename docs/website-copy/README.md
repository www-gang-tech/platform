# GANG website copy

Editorial draft · October 1, 2026

**Creative direction: Power has a place.**

A product-led website for GANG: large photographs, short statements, and specific information where it helps someone understand the object. The central idea is charging as part of the room. The language should feel as considered as the hardware.

## What informed the work

The review screened the 1,591 Markdown records available in the local private brain and identified 201 records with relevant brand, product, or launch language. It then examined the canonical company/product records, founder vision, founder-authored positioning, strategic workbook, specifications, certification correspondence, recent board notes, and creative deliverables. This is a targeted evidence review, not a claim to have manually read every email or unextracted attachment.

The consistent direction is a consumer hardware company beginning with wireless charging, with an emphasis on industrial design and the home. The customer's investment in their space is a more useful starting point than age or gadget enthusiasm. The website should make the function immediately understandable and let the product, materials, and setting establish its value.

## Working decisions

- **Prelaunch is confirmed by the owner.** The site focuses on product discovery and launch updates. Purchase copy is provided separately for activation when ordering opens.
- **GANG–1 is the confirmed public product name.** The owner selected the specification sheet's name on October 3, 2026. The existing `/objects/charger/` URL stays in place.
- **Use “four charging zones” to explain the format.** The website does not imply Apple Watch charging.
- **Lead with the object in a room.** Follow with what it is, how it is used, and what fits. Keep the product category in visible text.
- **Publish one product story.** With one established product, the main navigation can point directly to it instead of an almost empty catalog.
- **Keep technical facts exact.** The supplied specification sheet now supports development specifications, device listings, materials, and box contents. It does not establish final product certification, measured charging times, price, or installation instructions. See [Integration notes](INTEGRATION.md) for the source and publication decisions.

## Voice

Use short, complete sentences. Name the object and the action. One idea per visual. Let an evocative headline sit above a plain explanation.

| Use | Avoid |
| --- | --- |
| A wall-mounted wireless charging hub with four charging zones. | The ultimate all-in-one charging solution. |
| Charging, off the counter. | Revolutionize your space. |
| Check device compatibility. | Works with everything. |
| Explore GANG–1. | Discover the future. |
| Join launch updates. | Claim exclusive VIP access. |

“Luxury” describes the creative standard; it need not appear in customer copy. Express value through the actual object and the quality of information. Avoid invented scarcity, unearned superlatives, competitor comparisons, and unsupported durability or sustainability promises.

## Reference interpretation

[YEEZY](https://yeezy.com/) demonstrates how far a product grid can carry a page. [Teenage Engineering's OB–4 page](https://teenage.engineering/products/ob-4) pairs distinctive product presentation with functional explanation. The proposed GANG approach uses image-led restraint with a visible category description, compatibility information, and setup guidance. These are creative references, not evidence that a particular layout will achieve a given conversion rate.
