This is the public end of one editorial cycle. A private working note recorded alignment behaviour from an internal review. That note is not on this site. A Markdown draft in the website directory was written from it, then cut until every remaining sentence could be stood next to a public standard or a clearly labelled “in development” statement.

The [charger](/objects/charger/) page is that article. A later pass removed implied power and compatibility claims. The revision is the version you are reading around, not a changelog of private files. Studio saved the working Markdown. Release still means git review and a production build without editor controls.

On October 3, the supplied GANG–1 specification sheet added a new source for the product page: stated output, materials, power requirements, device listings, and box contents. The page now includes those specifications and the sheet itself. A specification records the intended product; testing and certification remain distinct forms of evidence.
