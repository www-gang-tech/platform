This policy applies to the public GANG website. It does not cover private studio systems, unpublished files, or third-party sites we link to.

## What this site is

The public site is static HTML built from Markdown in a git repository. Viewing a page does not create an account. Saving an edit on a local copy of the files does not send data to GANG.

## What we collect

**Mail you send.** If you write to [info@gang.tech](mailto:info@gang.tech), [support@gang.tech](mailto:support@gang.tech), or [press@gang.tech](mailto:press@gang.tech), we receive the address and the message you send. We use that to reply.

**Cart.** The cart, if present, is stored in your browser (`localStorage`). It does not go to our servers until there is a working checkout. There is no finished SKU on this site.

**Comments.** If a comment form is shown and you submit it, the fields you fill in are sent to the address configured for that form. Do not put unpublished specifications or private source maps in a comment.

**Studio login.** Studio and Ask are separate, authenticated surfaces. They are not this public site. Tokens and session data for those tools stay on the device and the private host that serves them.

## What we do not collect here

This public build does not add an analytics product, advertising pixels, or a mailing-list signup. If that changes, this page will change in the same git review as the rest of the site.

## Hosting

The deployed site is files on a host. The host will see ordinary web-server logs (such as IP address and the URL requested) according to that host’s own terms. We do not publish those logs.

## How long we keep mail

We keep correspondence as long as it is needed to answer you or to keep a record of a request. You can ask us to delete mail that is only about you by writing to [info@gang.tech](mailto:info@gang.tech).

## Children

This site is not directed at children.

## Changes

Edits to this policy are reviewed in git like other public pages. The `updated` date in the file is the date of the last published change.
