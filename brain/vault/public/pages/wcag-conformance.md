# Accessibility

GANG wants this website to be usable with a keyboard, a screen reader, and zoom. Pages are written toward WCAG 2.2 Level AA. This page does not report the result of a conformance audit.

## Feedback

If a page gets in the way, email [info@gang.tech](mailto:info@gang.tech?subject=Accessibility). The same address is on [Contact](/pages/contact/).

## How the pages are built

Articles and guides are HTML and CSS. Search and the cart run a short script in the browser. Images that carry information include a text alternative.
